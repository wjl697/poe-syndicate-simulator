# 辛迪加 —— 玩法介绍

《辛迪加》是一款以「黑色交易组织」为主题的策略推演游戏，玩家扮演辛迪加的核心决策者，通过**审讯、处决、背叛、商谈**等手段，一步步揭开四大部门的秘密，最终将整个组织收入囊中。

---

## 一、组织与成员

### 四大部门
| 部门 | 定位 |
|------|------|
| 运输部 | 物资与人员的调配 |
| 防卫部 | 组织的武力保障 |
| 科研部 | 情报与技术研究 |
| 调停部 | 内部纷争的仲裁 |

### 部门构成
- 每个部门 = **1 名首领 + 最多 4 名下属**（共 5 人上限）
- 还有**自由人**（无部门）与**在押人员**（审讯室中）

### 星级（等级）
- 成员星级 0~3 星，反映其在组织中的地位
- 星级影响情报产出、处决/商谈效果等

### 关系
成员之间存在三种关系：
- **信任**（绿色连线）
- **敌对**（红色连线）
- **中立**（无线）

关系会影响遭遇战的增援选择与可执行的操作。

---

## 二、回合与遭遇

### 一回合流程
每回合生成最多 **3 场部门遭遇**：
- **运输部 / 防卫部 二选一**（随机）
- **科研部**（必出）
- **调停部**（必出）

### 遭遇战
- 每场遭遇由 **1 名主成员 + 至多 3 名增援** 组成（上限 4 人）
- 遭遇成员在玩家实际遇到该场时才生成
- 增援来自：同部门下属、相关他部门成员、自由人

### 自由人支援规则
- 自由人可作为增援进入遭遇
- **数量受部门剩余空位限制**：部门满员（5 人）时自由人无法支援；非满员时支援数 ≤ 剩余空位
- 自由人默认权重较低（1 票），与主成员有关系时权重大幅提升（30 票）

### 主成员与首领
- 每场遭遇由 **1 名主成员**（部门下属）作为核心，再填充增援
- **首领参战**需要满足合规条件：
  - 首领不在押、在场上、未被本回合其他遭遇锁定
  - 且满足以下任一条件：
    - 主成员与首领**有关系线**（信任或敌对），**或**
    - 部门下属**总星级 ≥ 3**
- **总星级计算**：包含在押下属（仍计入）、未揭示的下属**默认按 1 星**计
- 首领合规后，通过「首领通道」判定实际是否参战（基础概率 5%，可被天赋/物品提升）

---

## 三、遭遇操作

遭遇战中对成员可执行以下操作：

| 操作 | 触发条件 | 效果 |
|------|---------|------|
| **释放** | 始终可用 | 无任何效果，组织无变化 |
| **审讯** | 始终可用 | 囚禁 3 回合，按星级产出情报 |
| **处决** | 3人及以上，或特定关系下 | 星级 +1，自由人可加入部门 |
| **背叛** | 仅剩 2 人时 | 破坏对方并与之敌对 |
| **商谈** | 仅剩 1 人时 | 获得随机奖励或触发机制 |

（详见 `遭遇战操作说明.md`）

---

## 四、情报与藏身处

### 情报系统
- 每个部门都有情报值（0~100%）
- 情报通过以下方式获得：
  - **审讯在押成员**：首领星级×3、下属星级×2、自由人 1（每回合）
  - **背叛/商谈**：部分效果直接增加部门情报
- 情报满 100% 时，该部门**藏身处解锁**，可发动突袭

### 情报衰减
- 部门情报满 100% 后，若 **3 次遭遇战内未突袭**，情报强制衰减至 90%

### 突袭藏身处
- 情报满 100% 时可突袭该部门安全屋
- 突袭后：
  - 该部门在押成员全部释放（星级 -1，1 星保持）
  - 原首领变为 0 星自由人
  - 新首领晋升（最高等级下属 → 自由人 → 他部门调任）
  - 部门情报重置为 0

---

## 五、审讯系统

### 审讯机制
- 最多同时 **3 人**在押
- 审讯第 4 人时，强制释放**最早入押**的成员（不发放剩余情报）
- 在押成员**每回合**为遭遇部门贡献情报，持续 3 回合

### 首领审讯
- 审讯首领立即**卸任**
- 新首领产生顺序：
  1. 部门内最高等级下属
  2. 无下属 → 从自由人中随机提拔
  3. 无自由人 → 从其他部门调任普通成员（星级重置 1；首领不可调任）

### 释放与降星
- 在押成员释放时星级 -1
- 降至 0 星则变为自由人（无部门）

---

## 六、部门补员

- 部门若仅剩首领（无下属），会**自动补员**：
  1. 优先从自由人中随机补 1 名下属
  2. 无自由人 → 强制释放该部门一名在押成员补充（星级 -1）

---

## 七、操作模式

| 模式 | 说明 |
|------|------|
| **经典模式** | 标准流程，系统随机预掷背叛/商谈效果 |
| **沙盒模式** | 自由布阵，玩家可自由选择背叛/商谈效果 |
| **画板模式** | 电子画板教学推演，可自由连线、模拟遭遇 |
