# 辛迪加遭遇战操作说明

本文档整理《辛迪加》遭遇战中**处决、审讯、背叛、商谈、释放**五种操作的效果、触发条件、详细说明与实际效果。数据来源：`scripts/gameplay/action_logic.gd`。

---

## 操作触发规则

| 剩余未处理成员数 | 可用操作 |
|-----------------|---------|
| ≥ 3 | 审讯 + 处决 + 释放 |
| 2 | 审讯 + 释放 +（按关系而定：信任→背叛 / 上下级→处决或背叛 / 其他→处决） |
| 1 | 审讯 + 商谈 + 释放 |

> 释放始终可用（中间按钮）。

---

## 一、处决（Execute）

### 触发条件
- 剩余成员数 ≥ 3 时必现
- 剩余成员数 = 2 时，非信任/非上下级关系时出现

### 显示说明
- 星级 < 3：`{目标人物} 等级 +1`
  - 处决自由人时追加一行：`{目标人物} 去往 {遭遇部门}`
- 星级 = 3：`【已达最大等级。无效果】`

### 实际效果
- 星级 < 3 → 星级 +1（上限 3）
- 星级 = 3 → 无升星效果
- 若为 0 星自由人 → 升星后加入当前遭遇部门（自由人通过支援进入遭遇时部门必有空位，因此总能加入）

---

## 二、审讯（Interrogate）

### 触发条件
- 始终可用（已被囚禁的成员不可选）

### 显示说明
`{目标人物}被囚禁{3}回合。+{N}{遭遇部门}情报每回合。释放后等级-1`

### 实际效果
- 囚禁目标，持续 3 回合
- 每回合为**遭遇部门**提供情报：
  - 首领：`星级 × 3`
  - 下属：`星级 × 2`
  - 自由人：固定 `1`
- 审讯首领立即卸任，新首领按以下顺序产生：
  1. 部门内最高等级下属 → 提拔为新首领
  2. 无下属 → 从自由人中随机提拔
  3. 无自由人 → 从其他部门随机调任一名**普通成员**担任首领（星级重置为 1；**首领不可被调任**）
- 释放时星级 -1；降至 0 星则变为自由人
- 最多同时 3 人在押；审讯第 4 人时强制释放最早入押的成员

---

## 三、背叛（Betray）

### 触发条件
- 剩余成员数 = 2
- 双方为信任关系，或执行者为上下级中的非首领一方时出现

### 可选效果（7 种）

| 效果名 | 显示说明 | 生效条件 | 实际效果 |
|--------|---------|---------|---------|
| 窃取情报 | `+6{目标部门}情报。{执行者}和{目标}变成敌对` | 存在目标成员 | 目标部门情报 +6；双方变敌对 |
| 窃取阶级 | `为{执行者}+{目标星级}等级。{目标}失去所有等级。{执行者}和{目标}变成敌对` | 存在目标成员 | 执行者星级 +目标星级（上限 3）；目标星级清零；双方变敌对 |
| 逐出组织 | `{目标}已从不朽辛迪加中被除名` | 存在目标成员 | 目标被逐出组织（从棋盘移除并触发替补替换） |
| 打压宿敌 | `{本部门}成员等级+1。{目标部门}成员等级-1。{执行者}和{目标}变成敌对` | 双方为不同部门 | 本部门全体星级 +1；目标部门全体星级 -1；双方变敌对。若目标部门首领因此降级，首领立即下台并由新首领替代 |
| 摧毁敌对部门装备 | `摧毁{目标部门}成员装备。{执行者}和{目标}变成敌对` | 双方为不同部门 | 目标部门全体装备清零；双方变敌对 |
| 篡位 | `{执行者}变为{本部门}的首领。{执行者}和{目标}变成敌对` | 执行者为上下级中的非首领一方 | 执行者成为本部门新首领；双方变敌对 |

---

## 四、商谈（Bargain）

### 触发条件
- 剩余成员数 = 1

### 可选效果（13 种）

| 效果名 | 显示说明 | 生效条件 | 实际效果 |
|--------|---------|---------|---------|
| 获取情报 | `+{N}{遭遇部门}情报` | 始终可用 | 情报量与星级相关：3星=8、2星=6、1星/0星=4 |
| 获取大量情报 | `+20{遭遇部门}情报` | 始终可用 | 遭遇部门情报 +20 |
| 结盟 | 见下方细分 | 场上存在可结盟成员 | 按目标关系处理 |
| 退出组织 | `{执行者}已从不朽辛迪加中被除名` | 始终可用 | 执行者被逐出组织 |
| 化解部门恩怨 | `移除{本部门}成员的所有死敌` | 本部门存在敌对关系 | 清除本部门全体成员的敌对关系 |
| 摧毁部门装备 | `摧毁{本部门}成员的所有装备` | 始终可用 | 本部门全体装备清零 |
| 调动职位 | `{执行者}去往{目标部门}。{目标}去往{本部门}` | 存在同星级同职务的其他部门成员 | 双方互换部门 |
| 劫狱 | `所有的囚犯都被释放了。+{N}{部门}情报 +{M}{部门}情报...` | 审讯室存在在押囚犯 | 释放全部囚犯；按部门分别获得情报 |
| 获取传奇 | `丢下一个传奇道具` | 始终可用 | 获得传奇道具 |
| 获取通货 | `丢下一些通货物品` | 始终可用 | 获得通货物品 |
| 获取隐匿 | `掉落一些加密物品` | 始终可用 | 获得加密物品 |
| 获取地图 | `丢下一张地图` | 始终可用 | 获得地图 |
| 获取甲虫 | `掉落一些圣甲虫` | 始终可用 | 获得圣甲虫 |

### 结盟（FORM_TRUST_ANY_GAIN_INTEL）细分

| 目标类型 | 显示说明 | 实际效果 |
|---------|---------|---------|
| 无敌对关系的自由人 | `{目标}去往{遭遇部门}。{执行者}和{目标}变为信任` | 目标升星(0→1) + 加入遭遇部门 + 变信任 |
| 敌对成员 | `{执行者}和{目标}变为中立。+4{目标部门}情报` | 关系变中立 + 目标部门情报 +4 |
| 一般关系成员（无关系的跨部门/同部门/首领） | `{执行者}和{目标}变为信任。+4{目标部门}情报` | 变信任 + 目标部门情报 +4 |

> **特别标注**：「敌对自由人」不作为结盟目标（候选池已排除）。自由人若与执行者敌对，不会被选为结盟目标。
> 结盟目标由系统**随机**从场上非信任、非敌对自由人成员中选取，执行时按目标类型执行对应操作。

---

## 五、释放（Release）

### 显示说明
`释放目标。你不会获得情报，辛迪加组织也不会有任何改变`

### 实际效果
- 释放目标，不会获得情报，辛迪加组织无任何改变

---

## 模式差异说明

- **沙盒模式**：背叛/商谈可从效果池中**自由选择**具体效果（悬停查看详细说明）。
- **经典模式**：系统**随机预掷**一个效果；未预掷时显示效果池中第一个有效效果的详细说明。
