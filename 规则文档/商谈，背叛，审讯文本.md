# 商谈：

调动职位：该成员与其他部门的同星级同职位成员互换部门。
显示文本例子：哈库去往科研部。卡美利亚去往调停部

结盟：该成员与另一个任意目前没有信任关系的成员建立信任关系，对方可以是成员也可以是首领，也可以是自己部门的首领，并获取对方部门的情报 。也可以和自由人达成信任关系，这种情况下，会将自由人拉拢到自己的部门。也可以和有背叛关系的人达成信任，信任后关系变为中立。
显示文本例子：
和一般成员达成信任：哈库和克雷尔变为信任。+4科研部情报
和自由人达成信任：瓦甘去往科研部。古夫和瓦甘变为信任
和有背叛关系的人达成信任：格拉维奇和哈库变为中立。+4调停部情报


获取大量情报：直接获得大量某部门的安全屋情报
显示文本例子：+16防卫部情报


获取情报：直接获得一定数量的某部门安全屋情报
显示文本例子：+6防卫部情报


退出组织：该成员自愿离开不朽辛迪加（换新人进来）
显示文本例子：里奥已从不朽辛迪加中被除名


劫狱：立刻释放当前监狱（审讯中）的所有成员，释放所有情报
显示文本例子：所有的囚犯都被释放了。+24 情报


摧毁部门装备：清除自己当前部门所有成员身上的强化装备
显示文本例子：摧毁运输部成员的所有装备

化解部门恩怨：清除当前部门内成员的所有宿敌关系
显示文本例子： 移除调停部成员的所有死敌

获取传奇：丢下一个传奇道具
显示文本例子：丢下一个传奇道具

获取通货：丢下一些通货物品
显示文本例子：丢下一些通货物品


获取隐匿：掉落一些隐匿物品
显示文本例子：掉落一些加密物品

获取地图：丢下一张异界地图
显示文本例子：丢下一张地图


获取圣甲虫：掉落一些异界圣甲虫
显示文本例子：掉落一 一些圣甲虫


# 背叛：

篡位：该成员取代其部门当前的头目（Leader）位置
显示文本例子：格拉维奇变为运输部的首领。格拉维奇和瓦里西变成敌对

逐出组织：将对方成员彻底踢出整个不朽辛迪加（换新人进来，新成员处于未被翻牌的状态）
显示文本例子：哈库已从不朽辛迪加中被除名


窃取阶级：偷取对方星级，对方失去所有星级。
显示文本例子：为艾尔雷恩3等级。古夫失去所有等级。艾尔雪恩和古夫变成敌对


窃取情报：通过背叛同伴来获得该部门的情报
显示文本例子：+6运输部情报。哈库和格拉维奇变成敌对

摧毁敌对部门装备：清除宿敌部门所有成员身上的强化装备「两个成员是不同部门」
显示文本例子：摧毁科研部成员装备


打压宿敌：降低宿敌的阶级，同时提升自己部门成员的阶级【部门首领的等级因为任何情况下降，他的位置会被下属取代】!
显示文本例子：调停部成员等级+1。防卫部成员等级-1


# 审讯

规则：情报获取的数量等于审讯人员星级乘以2，如果是审讯的是首领，那么是人员星级乘以3。如果审讯的是自由人，那么固定为1情报每回合。比如审讯一个2星的运输部成员，+4情报每回合，审讯3星的科研部首领，+9情报每回合，审讯自由人，+1情报每回合。
显示文本例子：哈库被囚禁3回合。+9运输部情报每回合。释放后等级-1
